## Notes
- **Chrome:** `ListLayout` contract at `src/components/ListLayout/index.tsx:1-52` (`title`, `primaryAction?`, `toolbar?`, `children`). Keep `DetailTabBar` for the General/Team switch, rendered in the content zone.
- **Grids:** `NewDataGrid` from `@mocho/ui/components`; `ActionsCell` from `mocho/components/DataGrid/ActionsCell`; `EmptyState` from `mocho/components/EmptyState`. Grid options: `rowHeight: 56`, `headerHeight: 44`, `pagination: true`, `paginationPageSize: 25`, `domLayout: 'normal'`. Loading via `loading={!hasLoadedOnce}`.
- **Cell renderers:** never inline — co-located `*CellRenderers.tsx`. Member grid needs an inline role `Select` renderer + `ActionsCell` (Remove). Invitation grid needs expiry + role-chip renderers + `ActionsCell` (Resend/Revoke, disabled while that row's op is pending).
- **Drawers:** each follows `CompanyInfoDrawer` — `({ onClose }) + useSelector(currentSettings)` → `EditDrawer` (dirty-form blocking built in) → Formik with that section's fields → on submit dispatch `updateSettingsRequest` with **current settings merged with edited fields** (full-object PUT). Register in `drawerRegistry` + `popupTypes`; open via `useDrawerActions().openDrawer('settingsFinancial', {...})`.
- **Role-gating:** `SectionHeader.onEdit` wired only when `isAdminSelector` is true → dispatchers get read-only sections with no pencils. Removes the prior "disabled fields + hidden Save" code.
- Existing Redux (`updateSettingsRequest`, `settingsSchema`, team actions/sagas) is reused unchanged — no store/saga/API changes.
