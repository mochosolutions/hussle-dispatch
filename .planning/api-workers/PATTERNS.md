## Critical decoupling note

The 12 module `index.ts` edits share **one identical refactor**: move the top-level `initialize*` / cron-`start()` call out of module scope into an exported function (`startBackground.ts` calls them). They are listed individually because each cites different self line ranges, but the change is mechanical and identical.

**Why per-file edits are mandatory, not just gating one call:** `src/app.ts` imports each feature router (`./loads`, `./drivers`, `./settlements`, `./agreements`, …). Importing the router loads that module's `index.ts`, whose top-level `initializeSubscriber()` runs **at import time** — so subscribers boot even in `ROLE=api`. Removing the two explicit side-effect imports (`./audit`, `./notifications`) is not enough; every module's import-time init must move behind an exported function. `src/settlements/index.ts`, `src/agreements/index.ts`, and `src/documents/index.ts` each start **two** things (a subscriber + a cron, or two subscribers) — handle both.
