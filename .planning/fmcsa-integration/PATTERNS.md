## Notes

- **No subscriber.** Service emits `fmcsa.lookup.completed` and `fmcsa.lookup.failed` as fire-and-forget observability events. No consumer of `fmcsa.lookup.*` events exists in v1 — consumers subscribe as they arise.
- **Cache adapter pattern.** `redisCacheAdapter.ts` is the only place `redisClient` is imported inside this module; it implements `CachePort` so `fmcsaService` stays pure and trivially testable with an in-memory fake.
- **Module signature.** `createFmcsaModule({ eventBus, logger })` — no prisma, no redis injected. Redis is accessed via the singleton inside the cache adapter.
