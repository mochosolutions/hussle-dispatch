- **Lift the Python schema verbatim** from notebook cell `37636f9d`. Do not rename fields. The TS `RateconExtractionResponse.extraction` type must mirror it exactly (use `openapi-typescript` against the FastAPI-generated OpenAPI doc, or hand-write a matching `interface ExtractionResult` in `src/ratecon-extraction/types/extractionTypes.ts`).
- **Lift the prompt verbatim** from cell `e4d3ed03`. Do not paraphrase.
- **The `intelPrefill` path is the only sanctioned form-init mechanism.** Add the ratecon prefill source alongside it; do not introduce a parallel mechanism.
- **Broker fuzzy match** belongs in `matchBroker.ts` as a pure function on a `CustomerQueryPort.findManyByOrg`. PG `pg_trgm` similarity would be ideal long-term but a simple normalized-Levenshtein over `Customer.name` is fine for V1 (10s of customers per org).
- **Redis buffer key** should be a uuidv7 (sortable, leakage-resistant). 30 min TTL set at write time, no expiry-refresh.
- **Stop count guardrail**: if `ExtractionResult.stops.length > 10`, log a warning but still return the data. Don't truncate.
- **Sample PDFs** copy from `/Users/jr/Development/Jupyter Notebook/ratecon_files/` into `ratecon-extraction-service/tests/fixtures/`. Before committing, eyeball each one — if any contain real driver phone numbers or other PII, scrub or replace with a synthetic sample.
- **Internal token** must be checked with a constant-time compare on the Python side (`hmac.compare_digest`).
