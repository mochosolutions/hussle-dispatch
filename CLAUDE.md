# Project Conventions

> Auto-generated by /bootstrap on 2026-03-01. Edit freely — bootstrap will not overwrite.

## Stack
- Runtime: Node.js (npm workspaces monorepo)
- Framework: React 18 + MUI v5
- State: Redux Toolkit + Redux Saga
- Forms: Formik + Yup
- Database: PostgreSQL via Prisma (planned), Redis (planned)
- Testing: Jest + React Testing Library
- Build: Vite
- Package manager: npm

## File Organization
- Shared UI library in `mocho-ui/` — multi-entry exports (`./redux`, `./forms`, `./components`, `./hooks`, `./utils`, `./types`)
- Dispatch app in `hussle-app-dispatch-ui/` — feature modules under `src/pages/<feature>/`
- Components: PascalCase folders with `index.tsx` re-export
- Utilities/hooks: camelCase single files, one function per file
- Tests co-located with source as `.test.tsx`
- Storybook stories co-located as `.stories.tsx`

## Naming Conventions
- Files: PascalCase for components (`ConfirmDialog.tsx`), camelCase for utils/hooks (`useConfig.ts`)
- Functions/methods: camelCase
- Types/interfaces: PascalCase, props suffixed with `Props` (`ConfirmDialogProps`)
- Redux slices: camelCase with `Slice` suffix (`uiSlice.ts`)
- Route files: PascalCase with `Routes` suffix (`HomeRoutes.tsx`)

## Import Style
- Order: React → MUI/external → internal types → internal utils → components
- `import type { Foo }` for type-only imports — never mix type and value imports
- Barrel exports from index.ts files for clean re-exports
- Path aliases in dispatch-ui: `components/*`, `pages/*`, `store`

## Error Handling
- Frontend: ErrorBoundary class component with fallback UI
- HTTP: Axios interceptors for 401 token refresh → retry or logout
- Typed errors: enum + interface pattern (e.g., `ImageUploadErrorType` + `ImageUploadError`)
- Never throw generic `Error` — use typed error classes

## API Patterns
- HTTP client: Axios with interceptors (`utils/axios.ts`)
- Auth: JWT bearer tokens (planned)
- Response envelope: `{ data }` for single, `{ data, meta }` for lists (planned)

## Frontend Patterns
- State: Redux Toolkit for client state, Redux Saga for async side effects
- Components: `React.FC<Props>` for shared, arrow functions for pages
- Styling: MUI `sx` prop exclusively — no CSS modules, Tailwind, or styled-components
- Forms: Formik + Yup validation, discriminated union field types in DynamicForm
- Shared components from `@mocho/ui` — check REGISTRY-mocho-ui.md before creating new ones
- Dirty Form Blocking: ALL drawer/form components must use `useDirtyFormBlocker` from `@mocho/ui/forms`. Closing a drawer with unsaved changes must show a confirmation dialog. Follow the carrier CompanyInfoDrawer pattern as reference.

## Testing Patterns
- Framework: Jest + React Testing Library
- Location: co-located `.test.tsx` or `__tests__/` subdirectory
- Render helper: `renderWithTheme()` from test-utils
- Style: AAA pattern (Arrange-Act-Assert), `describe`/`it` blocks
- Naming: `it('renders dialog when open is true')`
